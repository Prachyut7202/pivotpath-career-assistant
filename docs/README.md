## Evidence and integrity
Candidate skills reported on a resume or in a self-assessment are not automatically proven. Written-case ratings are formative and do not predict hiring. SQL execution, production reminders, cross-device accounts, hiring outcomes and product telemetry are outside the prototype. User session state is stored locally in the browser, with an export option. No private resumes or contact details should be committed to this public repository.
